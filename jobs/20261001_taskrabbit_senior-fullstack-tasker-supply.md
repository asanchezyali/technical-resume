## Job description

Taskrabbit's Tasker & Supply engineering team builds and maintains the Tasker side of the platform. Project-based contract to accelerate an architectural migration: a new Mobile Backend-for-Frontend (BFF), a TanStack Query refactor, and the deprecation of direct GraphQL calls. The engineer bridges the new backend endpoints and the mobile client. TDD and code reviews.

You will be:
- Working across the stack to connect new REST APIs in the BFF with the mobile client
- Refactoring to TanStack Query patterns across the application
- Removing legacy GraphQL and ensuring strict type safety with TypeScript
- Promoting consistency in how data is fetched, cached and invalidated across teams
- Code review and clear documentation

You should have: 5+ years, OO design, strong TypeScript on both frontend and backend, judgment on what belongs in the frontend vs the backend, unit testing / code review / design docs.
Might be a fit: strong communication, Ruby on Rails / React Native / React.js, TanStack Query, deep GraphQL to assist its safe removal.
